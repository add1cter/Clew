# Windows 自用分支

本仓库 fork 自 [miuuyy/Clew](https://github.com/miuuyy/Clew)，保留上游 MIT 许可证和作者署名。这里只维护 Windows x64 安装包；保留其它平台源码，便于合并上游更新。

## 本地修改

- Windows 较长的登录凭据拆分写入系统凭据库，读取时验证完整性；不使用明文文件保存令牌。
- 主题测验的题目、选项和解析使用知识图谱的语言；修改语言后重新生成旧语言的测验。
- 测验及完成判定遵循工作区的 `require_prerequisite_closure_for_completion` 设置。关闭时允许直接测验并完成目标主题，保留先修关系和提示，也不会自动完成先修主题。
- CI、打包和发布只运行 Windows x64；发布收集仍校验安装包、更新清单与打包冒烟结果。
- 新构建的更新检查和发布目标指向 `add1cter/Clew`。
- 中文标签采用适合中文的字体、屏幕字号和重叠避让；悬停查看完整标题及直接连接，点击锁定聚焦，点空白处清除。
- 保留原有分群云雾与章节配色。2D、3D 都支持节点拖动联动和鼠标轻推，阻尼与位置吸引力使节点逐渐回稳；这些动作调整视图位置，编辑布局模式下可显式保存布局。
- Clew Local 自用插件与桌面共用本机数据库，自动刷新学习进度；经审阅的进度修改带版本校验和可回退快照。安装及边界见[本地插件说明](LOCAL_PLUGIN.zh-CN.md)。

## 设置与数据

将知识图谱语言设为 `zh-CN`，并在需要时将上述先修设置设为 `false`。这些是各工作区的本地设置，不随源码提交。教材、学习记录、数据库、OAuth 回调链接及凭据不属于这个仓库。

## 构建与更新

按 [桌面开发说明](DESKTOP.md) 安装依赖。在 Windows 运行 `npm run package -- --win --x64 --publish never` 生成安装包。GitHub Actions 的 Release 工作流也可以手动运行并下载构建产物。标签构建会准备草稿发布，需仓库所有者发布后才会出现在更新检查中。

本分支用于个人使用，不自动向上游提交 PR。
